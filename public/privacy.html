Хранение и отправка данных

Расписание

Файл разбирается в браузере. Приложение сохраняет извлечённое расписание в локальном хранилище браузера и читает его при следующем открытии страницы «Сегодня». Чтобы удалить копию, нажмите «Удалить расписание» на этой странице.

Редактор карты

Редактор сохраняет закрытия переходов, их причины и историю версий в браузере. Данные читает локальный предпросмотр. Экспорт JSON скачивает историю на устройство. Чтобы очистить историю, удалите данные сайта в настройках браузера.

Сообщения из формы связи

При отправке имя, адрес почты, тема, номер кабинета и текст сообщения передаются через EmailJS на адрес получателя формы. Адрес почты нужен для ответа на обращение.

Ссылки на маршрут и программу

Ссылка на маршрут содержит точки старта и назначения. Ссылка на программу прогулки содержит выбранные остановки. Эти параметры доступны каждому, у кого есть ссылка. Ссылки на Google Карты и сайт университета открывают внешние сервисы.
