# Приложение «внутри.»

При изменениях HTML, CSS или клиентского JavaScript на любой странице приложения сначала подбери руководство через `npx.cmd -y modern-web-guidance@latest search "<query>"`, затем загрузи его через `npx.cmd -y modern-web-guidance@latest retrieve "<guide-id>"`. В других оболочках используй `npx`. Сверь решение с рекомендациями по доступности и совместимости целевых браузеров.
